HELP L232 Command Help

Syntax
HELP
HELP,<command name>

Description
Typing HELP by itself will print a list of the currently available L232 commands with brief descriptions. To get command specific help, use the HELP,<command name> syntax

Example
Request help for the Keypad Button Press command

L232> HELP,KBP
Keypad button press
Usage: KBP,<address>,<button number>
