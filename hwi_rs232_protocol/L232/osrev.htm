OSREV Request O/S revision

Syntax
OSREV

Processor responds with the following for each processor in the system
Processor <processor address> O/S Rev = <O/S Rev><processor type>

Parameter Description Format
processor address The processor address Processor 1-16
O/S Rev Revision number of the currently installed O/S O/S Rev: 1-100.1-100.1-100
Processor Type Number corresponding to the processor model T1-27

Processor type and corresponding processor type
Processor Type Processor Model
2 H-RFP-2P
H-RFP-1P
3 4-Series Proc
4, 13, 21 H4P5
5, 12, 20 H4P5-HRL
6, 9, 14, 15, 17, 23 HRP5
7, 8, 10, 11, 18, 19 H8P5
22, 27 HP5-AMX
25 P5 BLT (Chronos)
26 AMX Interface Processor

Description
Returns the address, O/S revision, and processor type for all processors in the system

Example
Request the O/S revisions of a system with 3 processors

L232> OSREV
Processor 01 O/S Rev : 01.49.00 T11
Processor 02 O/S Rev : 01.49.00 T13
Processor 03 O/S Rev : 01.49.00 T11
