PROMPTOFF Turn off the L232> Prompt

Syntax
PROMPTOFF

Description
When the L232> prompt is turned off, a new L232> will not be printed after each command execution. This can be useful when communicating with external A/V systems that would just ignore the prompt.

Example
Turn the L232> prompt off

L232> PROMPTOFF

See Also
