RDST Request Daylight Savings Time

Syntax
RDST

Processor Responds
"DST = TRUE", or "DST = FALSE", or "The database does not support manual dst configuration".

Description
If manual configuration of DST is enabled then the processcor responds "DST = TRUE", or "DST = FALSE". If the system is configured to keep track of DST automatically then the processor will respond "The database does not support manual dst configuration".

Example
Request daylight savings time, daylight savings time is on

L232> RDST

DST = TRUE

See Also
